AJITH T — PREMIUM DARK PORTFOLIO
================================

This package contains redesigned:
- index.html
- style.css
- script.js

IMPORTANT:
1. Keep your existing "assets" folder unchanged.
2. Replace the old index.html, style.css and script.js with these files.
3. Do not delete or rename your assets folder.
4. Preview locally by opening index.html, or publish through GitHub Pages.

GitHub upload:
- Open https://github.com/Ajith8754/My-Portfolio-Ajith
- Select Add file > Upload files
- Upload these three files to the repository root, replacing the old files
- Commit changes to the main branch
- Wait for GitHub Pages to rebuild, then refresh your portfolio URL

Before publishing, verify:
- Profile image at assets/profile photo.jpeg
- Project images under assets/uiux/ and assets/
- Certificate images under assets/Certification/
- Confirm your current job title and dates are accurate.
- Add your resume PDF and link it if you want a Download CV button.

No GitHub account credentials are included or needed in this ZIP.
